1. Preliminaries: Graphs as Data Structures

Let \( \mathcal{G} = (\mathcal{V}, \mathcal{E}) \) be a graph where \( \mathcal{V} = \{v_1, v_2, \dots, v_N\} \) is the set of \(N\) nodes and \( \mathcal{E} \subseteq \mathcal{V} \times \mathcal{V} \) is the set of edges.

We define:

  • Adjacency matrix \( \mathbf{A} \in \{0,1\}^{N \times N} \), where \(A_{ij}=1\) iff \( (v_i,v_j)\in\mathcal{E} \).
  • Degree matrix \( \mathbf{D}=\mathrm{diag}(d_1,d_2,\dots,d_N) \), where \( d_i=\sum_j A_{ij} \).
  • Node feature matrix \( \mathbf{X}\in\mathbb{R}^{N\times F} \), where each row \( \mathbf{x}_i\in\mathbb{R}^F \) is the feature vector of node \(v_i\).

Intuition. Think of a social network. Each person is a node with features (age, interests, etc.), and friendships are edges. The adjacency matrix is the “who-knows-whom” lookup table, and the degree matrix tells you how many friends each person has.

2. The Core Problem: Why Can't We Just Use Convolutional Neural Networks or Multi-Layer Perceptrons?

Standard neural networks assume data lives on a regular grid (images → 2D grid, sequences → 1D grid). Graphs have irregular topology: each node has a different number of neighbors, there is no canonical ordering, and the structure itself carries information.

A Multi-Layer Perceptron applied independently to each node's features \( \mathbf{x}_i \) would be:

\[ \mathbf{h}_i = \sigma(\mathbf{W}\mathbf{x}_i + \mathbf{b}) \]

This completely ignores the graph structure — node \(v_i\) learns nothing from its neighbors. We need a mechanism to aggregate neighborhood information while respecting the permutation-invariant nature of graphs.

3. Graph Neural Networks: The Message-Passing Framework

3.1 The General Message-Passing Neural Network

Almost all Graph Neural Networks can be unified under the message-passing paradigm (Gilmer et al., 2017). At layer \(l\), each node \(v_i\) updates its representation through three operations:

Step 1 — Message computation

\[ \mathbf{m}_{ij}^{(l)} = \phi\!\left(\mathbf{h}_i^{(l)}, \mathbf{h}_j^{(l)}, \mathbf{e}_{ij}\right), \quad \forall j \in \mathcal{N}(i) \]

where \( \mathcal{N}(i)=\{j : (v_i,v_j)\in\mathcal{E}\}\) is the neighborhood of node \(i\), \( \phi \) is a message function, and \( \mathbf{e}_{ij} \) is an optional edge feature.

Step 2 — Aggregation

\[ \mathbf{m}_i^{(l)} = \bigoplus_{j \in \mathcal{N}(i)} \mathbf{m}_{ij}^{(l)} \]

where \( \bigoplus \) is a permutation-invariant aggregation (sum, mean, max, etc.).

Step 3 — Update

\[ \mathbf{h}_i^{(l+1)} = \psi\!\left(\mathbf{h}_i^{(l)}, \mathbf{m}_i^{(l)}\right) \]

where \( \psi \) is an update function.

Intuition. Imagine you are at a party. At each “round” of conversation (layer), you listen to what each of your friends is saying (message), combine all their opinions (aggregate), and update your own understanding (update). After \(L\) rounds, you have indirectly heard from friends-of-friends up to \(L\) hops away.

3.2 Graph Convolutional Network — Kipf & Welling (2017)

The Graph Convolutional Network is a foundational instantiation of this framework. It arises from simplifying spectral graph convolutions.

Spectral motivation. The graph Laplacian is \( \mathbf{L} = \mathbf{D} - \mathbf{A} \), and its normalized form is:

\[ \tilde{\mathbf{L}} = \mathbf{I}_N - \mathbf{D}^{-1/2}\mathbf{A}\mathbf{D}^{-1/2} \]

A spectral convolution on graphs is defined via the eigendecomposition \( \tilde{\mathbf{L}} = \mathbf{U}\mathbf{\Lambda}\mathbf{U}^\top \):

\[ \mathbf{x} *_{\mathcal{G}} \mathbf{g}_\theta = \mathbf{U} \, g_\theta(\mathbf{\Lambda}) \, \mathbf{U}^\top \mathbf{x} \]

This is \(O(N^2)\) and requires eigenvectors. Through approximations (Chebyshev polynomials truncated to first order), Kipf & Welling arrive at:

\[ \mathbf{H}^{(l+1)} = \sigma\!\left(\hat{\mathbf{A}} \mathbf{H}^{(l)} \mathbf{W}^{(l)}\right) \]

where \( \hat{\mathbf{A}} = \tilde{\mathbf{D}}^{-1/2}\tilde{\mathbf{A}}\tilde{\mathbf{D}}^{-1/2} \), \( \tilde{\mathbf{A}}=\mathbf{A}+\mathbf{I}_N \) (self-loops), and \( \tilde{\mathbf{D}}_{ii}=\sum_j \tilde{A}_{ij} \).

Per-node form (message passing):

\[ \mathbf{h}_i^{(l+1)} = \sigma\!\left( \sum_{j \in \mathcal{N}(i)\cup\{i\}} \frac{1}{\sqrt{\tilde{d}_i \tilde{d}_j}} \mathbf{W}^{(l)} \mathbf{h}_j^{(l)} \right) \]

Intuition. Each node computes a weighted average of its neighbors’ (and its own) features, then applies a linear transformation and nonlinearity. The term \( \frac{1}{\sqrt{\tilde{d}_i \tilde{d}_j}} \) normalizes by degrees so high-degree nodes do not dominate.

3.3 The Fundamental Limitation of Graph Convolutional Networks

In Graph Convolutional Networks, the neighbor weight is:

\[ c_{ij} = \frac{1}{\sqrt{\tilde{d}_i \tilde{d}_j}} \]

This depends only on topology (degrees), not on features \( \mathbf{h}_i, \mathbf{h}_j \). It is a static, isotropic weighting scheme.

In many settings, not all neighbors are equally important. We want anisotropic, data-dependent weights — exactly what attention provides.

4. The Attention Mechanism: A Brief Recap

Given a query \( \mathbf{q} \), keys \( \{\mathbf{k}_j\} \), and values \( \{\mathbf{v}_j\} \), attention computes:

\[ \mathrm{Attention}(\mathbf{q}, \mathbf{K}, \mathbf{V}) = \sum_j \alpha_j \mathbf{v}_j \]

where:

\[ \alpha_j = \frac{\exp(e(\mathbf{q}, \mathbf{k}_j))}{\sum_{j'} \exp(e(\mathbf{q}, \mathbf{k}_{j'}))} \]

and \( e(\cdot,\cdot) \) is a compatibility function (dot-product, additive, etc.).

Intuition. Attention is a soft dictionary lookup: compute relevance scores for each entry and return a weighted blend of values.

5. Graph Attention Networks — Veličković et al. (2018)

5.1 Core Idea

Replace the fixed normalization coefficients \(c_{ij}\) of Graph Convolutional Networks with learned, data-dependent attention coefficients \( \alpha_{ij} \) computed from node features.

5.2 Step-by-Step Mathematical Derivation

Input: Node features \( \mathbf{h}=\{\mathbf{h}_1,\dots,\mathbf{h}_N\} \), where \( \mathbf{h}_i\in\mathbb{R}^F \).

Output: Updated node features \( \mathbf{h}'=\{\mathbf{h}'_1,\dots,\mathbf{h}'_N\} \), where \( \mathbf{h}'_i\in\mathbb{R}^{F'} \).

Step 1: Shared Linear Transformation

\[ \mathbf{z}_i = \mathbf{W}\mathbf{h}_i \in \mathbb{R}^{F'} \]

This projects nodes into a common latent space of dimension \(F'\) where attention scores can be computed.

Step 2: Pairwise Attention Coefficients (Raw Scores)

\[ e_{ij} = \mathrm{LeakyReLU}\!\left( \mathbf{a}^\top [\mathbf{z}_i \| \mathbf{z}_j] \right) \]

where \( [\mathbf{z}_i \| \mathbf{z}_j]\in\mathbb{R}^{2F'} \) is concatenation and \( \mathbf{a}\in\mathbb{R}^{2F'} \) is learnable.

Unpacking the math. Split \( \mathbf{a}=[\mathbf{a}_1 \| \mathbf{a}_2] \), \( \mathbf{a}_1,\mathbf{a}_2\in\mathbb{R}^{F'} \):

\[ \mathbf{a}^\top [\mathbf{z}_i \| \mathbf{z}_j] = \mathbf{a}_1^\top \mathbf{z}_i + \mathbf{a}_2^\top \mathbf{z}_j \]

Intuition. The score combines a receiver-side term (node \(i\)) and a sender-side term (neighbor \(j\)). This is additive attention.

Step 3: Masked Attention (Graph Structure Injection)

Compute \(e_{ij}\) only for \(j \in \mathcal{N}(i)\cup\{i\}\). Formally:

\[ \mathrm{Mask}(i,j)= \begin{cases} e_{ij} & \text{if } j\in\mathcal{N}(i)\cup\{i\} \\ -\infty & \text{otherwise} \end{cases} \]

Step 4: Softmax Normalization

\[ \alpha_{ij} = \mathrm{softmax}_j(e_{ij}) = \frac{\exp(e_{ij})}{\sum_{k\in\mathcal{N}(i)\cup\{i\}} \exp(e_{ik})} \]

  • \(\alpha_{ij} \ge 0\)
  • \(\sum_{j\in\mathcal{N}(i)\cup\{i\}} \alpha_{ij}=1\)
  • Asymmetric in general: \(\alpha_{ij}\neq\alpha_{ji}\)

Step 5: Neighborhood Aggregation

\[ \mathbf{h}'_i = \sigma\!\left( \sum_{j\in\mathcal{N}(i)\cup\{i\}} \alpha_{ij}\mathbf{z}_j \right) = \sigma\!\left( \sum_{j\in\mathcal{N}(i)\cup\{i\}} \alpha_{ij}\mathbf{W}\mathbf{h}_j \right) \]

Comparison with Graph Convolutional Networks

Graph Convolutional Network Graph Attention Network
Aggregation \(\mathbf{h}'_i = \sigma(\sum_j c_{ij}\mathbf{W}\mathbf{h}_j)\) \(\mathbf{h}'_i = \sigma(\sum_j \alpha_{ij}\mathbf{W}\mathbf{h}_j)\)
Weights \(c_{ij}=\frac{1}{\sqrt{\tilde{d}_i\tilde{d}_j}}\) (fixed) \(\alpha_{ij}=\mathrm{softmax}_j(e_{ij})\) (learned)
Parameters \(\mathbf{W}\) \(\mathbf{W},\mathbf{a}\)

5.3 Multi-Head Attention

Graph Attention Networks use \(K\) attention heads, each with parameters \((\mathbf{W}^k,\mathbf{a}^k)\).

Intermediate layers (concatenation):

\[ \mathbf{h}'_i = \big\|_{k=1}^K \sigma\!\left( \sum_{j\in\mathcal{N}(i)\cup\{i\}} \alpha_{ij}^k \mathbf{W}^k \mathbf{h}_j \right) \]

Final layer (averaging):

\[ \mathbf{h}'_i = \sigma\!\left( \frac{1}{K}\sum_{k=1}^K \sum_{j\in\mathcal{N}(i)\cup\{i\}} \alpha_{ij}^k \mathbf{W}^k \mathbf{h}_j \right) \]

Intuition. Multi-head attention provides multiple “perspectives” for neighbor importance. Concatenation preserves all perspectives; averaging produces a consensus.

5.4 Computational Complexity Analysis

For a single Graph Attention Network layer with \(K\) heads:

Operation Complexity
Linear projection \((\mathbf{W}^k\mathbf{h}_j)\) for all nodes and heads \(O(K\cdot N\cdot F\cdot F')\)
Attention scores \((e_{ij})\) for all edges \(O(K\cdot |\mathcal{E}|\cdot F')\)
Softmax normalization \(O(K\cdot |\mathcal{E}|)\)
Aggregation \(O(K\cdot |\mathcal{E}|\cdot F')\)
Total \(O(K\cdot N\cdot F\cdot F' + K\cdot |\mathcal{E}|\cdot F')\)

For sparse graphs, \( |\mathcal{E}| \ll N^2 \), keeping this efficient and in the same complexity class as Graph Convolutional Networks (up to constant factors).

5.5 Key Theoretical Properties

Property 1: Permutation Equivariance. For any permutation matrix \(\mathbf{P}\):

\[ \mathrm{GAT}(\mathbf{P}\mathbf{H}, \mathbf{P}\mathbf{A}\mathbf{P}^\top) = \mathbf{P}\cdot \mathrm{GAT}(\mathbf{H}, \mathbf{A}) \]

This holds because attention coefficients depend on features, not node indices.

Property 2: Graph Convolutional Networks as a special case. If we fix \(\alpha_{ij}=\frac{1}{|\mathcal{N}(i)\cup\{i\}|}\) (uniform attention), Graph Attention Networks reduce to a mean-aggregation Graph Neural Network similar to Graph Convolutional Networks (without degree normalization).

Property 3: Expressivity. Graph Attention Networks can assign different importances to different neighbors of the same node, which is not possible in Graph Convolutional Networks. Under mild assumptions, the realizable function class of Graph Attention Networks strictly contains that of Graph Convolutional Networks.

6. GATv2: Fixing the Static Attention Problem — Brody et al. (2022)

6.1 The Problem with Graph Attention Networks Attention

Recall the Graph Attention Networks scoring function decomposes as:

\[ e_{ij} = \mathrm{LeakyReLU}(\mathbf{a}_1^\top \mathbf{W}\mathbf{h}_i + \mathbf{a}_2^\top \mathbf{W}\mathbf{h}_j) \]

Because \(\mathbf{a}_1^\top \mathbf{W}\mathbf{h}_i\) is constant across all neighbors \(j\) for node \(i\), the ranking of neighbors is determined entirely by \(\mathbf{a}_2^\top \mathbf{W}\mathbf{h}_j\). This yields static attention — ranking does not depend on the query node.

Formally, for any two nodes \(i,i'\) sharing the same neighborhood, \(\mathrm{argsort}_j(\alpha_{ij})=\mathrm{argsort}_j(\alpha_{i'j})\).

6.2 GATv2: Dynamic Attention

GATv2 applies the nonlinearity before the final projection:

\[ e_{ij}^{\mathrm{v2}} = \mathbf{a}^\top \mathrm{LeakyReLU}\!\left(\mathbf{W}[\mathbf{h}_i \| \mathbf{h}_j]\right) \]

Or equivalently:

\[ e_{ij}^{\mathrm{v2}} = \mathbf{a}^\top \mathrm{LeakyReLU}\!\left(\mathbf{W}_1\mathbf{h}_i + \mathbf{W}_2\mathbf{h}_j\right) \]

This introduces interactions between \(\mathbf{h}_i\) and \(\mathbf{h}_j\) before the final projection, enabling dynamic attention.

Intuition. Original Graph Attention Networks evaluate each neighbor’s “quality” mostly independently. GATv2 evaluates neighbors relative to the query node’s state — choosing whom to listen to depends on the current context.

7. Putting It All Together: The Graph Attention Networks Pipeline

For node classification on graph \( \mathcal{G} \) with \(C\) classes:

\[ \underbrace{\mathbf{X} \in \mathbb{R}^{N \times F}}_{\text{Input features}} \xrightarrow{\text{GAT Layer 1}} \underbrace{\mathbf{H}^{(1)} \in \mathbb{R}^{N \times KF'}}_{\text{Multi-head concatenation}} \xrightarrow{\text{GAT Layer 2}} \underbrace{\mathbf{H}^{(2)} \in \mathbb{R}^{N \times C}}_{\text{Multi-head averaging}} \xrightarrow{\mathrm{softmax}} \hat{\mathbf{Y}} \in \mathbb{R}^{N \times C} \]

The loss is cross-entropy over labeled nodes \( \mathcal{V}_L \subseteq \mathcal{V} \):

\[ \mathcal{L} = -\sum_{i \in \mathcal{V}_L} \sum_{c=1}^{C} y_{ic} \log \hat{y}_{ic} \]

Parameters \( \{\mathbf{W}^k, \mathbf{a}^k\} \) are trained end-to-end via backpropagation.
